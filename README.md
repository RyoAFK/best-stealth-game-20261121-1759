HUSHFALL is a tiny top-down stealth caper. You are Wren, the quietest thief in the city, emptying the Auric Club room by room: lift every gem and reach the exit without ever being seen. Wardens patrol on looping routes with lamplit vision cones that walls and crates block; their suspicion builds as a meter — freeze when a warden stares, break line of sight, hide crouched in ferns and shadow pools, and never sprint within earshot, because noise brings them to look. Three hand-designed rooms (the Counting House, the Gallery of Glass, the Gilded Vault), escalating patrols, ghost-run scoring for finishing a room unnoticed. The game is plain static files under `game/` — no build step, no network, just open it in a browser.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

Controls: WASD / arrow keys move, C crouches, Shift sprints (loud), R retries a room, Enter advances.
